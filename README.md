# God's Plan · Secure Canvas

Herramienta para pegar código HTML y ver la vista previa al instante.

**Sitio:** https://canvas.godsplan.site

## Qué incluye

- Editor de código con vista previa en vivo

## Tecnología

HTML, React (en el navegador) y Tailwind CSS.

## Probarlo en tu computadora

No necesita instalación: abre `index.html` en el navegador (usa librerías por CDN, así que requiere internet).
